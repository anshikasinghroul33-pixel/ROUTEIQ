# 🚚 RouteIQ — Intelligent Delivery Operations Platform

RouteIQ is an intelligent delivery operations platform designed to help delivery teams monitor and manage orders, riders, restaurants, and operational performance through a centralized dashboard.

## Overview

RouteIQ focuses on the internal operations side of a food-delivery ecosystem rather than customer-facing food ordering. The platform provides a centralized view of delivery activity, rider operations, restaurant performance, analytics, and operational alerts.

## Current Features

- 🔐 Login & authentication UI
- 🏠 Operations dashboard
- 📦 Order management and tracking
- 🔎 Order search and status filtering
- 📄 Order pagination and detailed order view
- 🗺️ Live operations monitoring
- 🚴 Rider monitoring
- 🍽️ Restaurant monitoring
- 📊 Delivery performance analytics
- 🔔 Operational delay alerts
- 🌙 Dark / Light mode
- 📱 Responsive interface

## Technology Stack

- HTML5
- CSS3 / Tailwind CSS
- JavaScript
- Responsive UI
- Demo / Mock Data

## Project Status

🚧 **Currently under development**

The current version focuses on the frontend operations dashboard and user interface. Backend services, database integration, authentication, real-time data, and ETA/delay prediction are planned for subsequent development phases.
